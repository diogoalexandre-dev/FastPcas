# FastPcas — ORÇAFAST

Simulador de orçamento instantâneo de peças usinadas para a FastPeças Diadema (empresa fictícia), desenvolvido como atividade do curso técnico de Desenvolvimento de Sistemas.

**Acesse:** https://diogoalexandre-dev.github.io/FastPcas/

## Como funciona

- O usuário escolhe o material (alumínio, aço carbono, aço inox ou latão/bronze), o tamanho da peça em cm e a quantidade.
- O preço unitário é calculado por centímetro de material mais um custo fixo de usinagem por peça.
- Descontos por volume são aplicados automaticamente: 5% de 51 a 100 peças e 10% acima de 100.
- O orçamento estimado pode ser enviado pelo WhatsApp para confirmação.

## Tecnologias

HTML, CSS e JavaScript, sem dependências.

## Estrutura

- `index.html`: página do simulador
- `style.css`: estilos e animações
- `script.js`: regras de preço e interação com a página
